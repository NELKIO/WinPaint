# Browser WinPaint Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Publish a usable lightweight editor alongside desktop releases.

**Architecture:** A static document owns one Canvas 2D raster and a bounded undo/redo history. A separate Pages workflow tests and deploys only the static directory.

**Tech Stack:** HTML, CSS, JavaScript, Python unittest, Playwright, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-23-pages-design.md`

## Global Constraints

Russian UI; local PNG processing only; relative asset URLs; project path `/WinPaint/`; leave tag-triggered releases intact.

### 1. Preserve desktop history fixes

- [ ] Verify `tests/test_history.py` against `src/winpaint/paint.py` with `PYTHONPATH=src python3 -m unittest discover -s tests -v`. Four tests must pass.
- [ ] Commit the verified desktop changes on the feature branch.

### 2. Implement and verify the static editor

- [ ] Add `tests/browser/test_editor.py`: serve the site at `/WinPaint/` and use real pointer input. Assert white → selected color → white → selected color for a stroke, undo and redo. Verify eraser, width and redo invalidation. Download the actual PNG and re-import it. Invalid imports must preserve pixels.
- [ ] Run `python3 -m unittest discover -s tests/browser -v` against the missing editor and confirm failure.
- [ ] Add `web/index.html`, `web/style.css`, `web/editor.js`. Use pointer capture and scaled coordinates; snapshot once per stroke; validate PNG header dimensions before decoding and swap the bitmap only on success. Limit undo and redo together to 64 MiB. Disable history actions when unavailable.
- [ ] Re-run browser tests and verify the desktop suite. Commit editor, tests and README link.

### 3. Publish and verify

- [ ] Add `.github/workflows/pages.yml` for pushes to `main` and manual dispatch. Run browser and desktop tests before configuring, uploading and deploying the `web/` artifact. Do not modify release tags.
- [ ] Verify the branch diff, enable Pages with workflow builds, fast-forward the default branch without force, watch the deployment, and run the browser suite against `https://nelkio.github.io/WinPaint/`.
