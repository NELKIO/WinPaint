# Браузерный WinPaint

На GitHub Pages по пути `/WinPaint/` открывается облегчённый русскоязычный редактор. Это не эмуляция PyQt5: HTML Canvas работает без установки, сервера, телеметрии и отправки изображений. На странице есть ссылка на полную версию в GitHub Releases.

- Отдельный каталог `web/`: статические HTML, CSS и JavaScript с относительными путями. Белый холст, кисть с выбором цвета и толщины, белый ластик. Мышь, перо и касание используют один набор pointer-событий; координаты пересчитываются при масштабировании страницы.
- Один штрих — один шаг истории. Отмена/повтор восстанавливают пиксели; новый штрих сбрасывает повтор. История ограничена по памяти. Импорт PNG заменяет холст после успешного декодирования, сбрасывает историю; ошибка сохраняет текущий рисунок. Ограничить размер импортируемых изображений. Экспорт скачивает PNG локально.
- Самостоятельный workflow Pages для `main`, не меняющий workflow релизов по тегам. Публикуется только `web/`.
- Проверка: операции с холстом в Chromium по пикселям, включая отмену/повтор, импорт/экспорт PNG, ссылки и работу под префиксом `/WinPaint/`; после публикации проверить публичный URL. Для десктопа — регрессии истории и состояния документа в offscreen Qt.
